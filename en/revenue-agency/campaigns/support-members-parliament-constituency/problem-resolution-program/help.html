Help with Connect from Canada Post

Canada Post Connect support (1-877-376-1212)

Contact Connect support for:

  • login issues or password resets
  • account verification;
  • system errors;
  • session timeouts; or
  • other technical issues related to the Connect platform itself.

If the issue is not resolved, contact Problem Resolution HQ. 

Problem Resolution program Headquarters mailbox

Contact Problem Resolution program for questions about:

  • submitting referrals;
  • intake processes; or
  • changes to participants in your office’s intake conversation.

The Problem Resolution program service does not provide technical support for Canada Post Connect accounts, but will assist with Problem Resolution program-specific intake and process questions as required.

Problem Resolution program Team Leaders

For urgent situations or follow-up after the five business day acknowledgment period, contact the appropriate Problem Resolution program Team Leader using the contact information provided to MP offices.

The Problem Resolution program service does not provide technical support for Canada Post Connect accounts, but will assist with Problem Resolution program-specific intake and process questions as required.
